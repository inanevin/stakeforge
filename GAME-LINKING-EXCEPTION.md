# Stakeforge Game Linking Exception — Version 1.0

## 1. Additional permission

As an additional permission under section 7 of the GNU General Public License, version 3 (“GPLv3”), the copyright holders granting this exception permit you to combine or link modified or unmodified Stakeforge with Independent Game Code, statically or dynamically, and distribute the resulting Game as described below.

This permission applies whether you use a prebuilt editor or runtime, compile Stakeforge yourself, or modify Stakeforge before making the Game.

## 2. Definitions

“Independent Game Code” means separately authored code implementing the content or behavior of a particular Game, which uses Stakeforge’s interfaces and is not otherwise copied or adapted from Stakeforge.

“Game” means an interactive game distributed to end users for play, including its updates, downloadable content, and components supplied to run that game.

“Game Runtime” means the modified or unmodified Stakeforge code incorporated into or supplied with a Game to run that Game. It may be embedded in an executable or supplied in separate libraries or executable components, including components delivered through a separate download for that Game.

A Game may include or be accompanied by level editors and modding tools intended for creating or changing content for that particular Game. These qualify for the same permission, including when supplied separately, provided they do not provide a general-purpose facility for creating or exporting independent games or other applications.

A standalone engine, engine SDK, general-purpose editor, or game-development framework does not qualify merely because it is bundled with a Game, includes a playable demonstration, or is described as a Game or modding tool. Its actual functionality and distribution determine whether it qualifies.

Moving, translating, or adapting Stakeforge code into another file, module, library, or executable does not make that code Independent Game Code.

## 3. Proprietary games and assets

You may distribute Independent Game Code under proprietary terms and charge for the resulting Game.

Solely because Independent Game Code is combined with Stakeforge as permitted by this exception, you are not required to provide its source code or object files for relinking.

The requirement in GPLv3 section 5(c) to license a combined work as a whole under GPLv3 is waived to the extent necessary to distribute Independent Game Code under terms of your choice. Those terms must not restrict recipients' rights under GPLv3 and this exception in the Stakeforge portions.

Independently authored game assets, including artwork, models, textures, audio, and narrative content, are not required to be disclosed or licensed under GPLv3 solely because they are loaded, processed, or distributed with the Game.

This permission includes incorporating material from Stakeforge’s public API headers into compiled Game code to the extent necessary for ordinary use of those APIs, including inline functions and templates.

## 4. Game Runtime source exception

When distributing a Game Runtime in object-code form as part of a Game distribution permitted by this exception, you are not required to disclose, publish, provide, offer, or arrange access to the Corresponding Source of that Game Runtime, including any modifications you made to Stakeforge.

The source-delivery and source-offer requirements of GPLv3 section 6 are waived for that distribution. You are also not required to provide Installation Information, installation keys, relinkable object files, or facilities for rebuilding, replacing, or relinking the Game Runtime. To the extent any other GPLv3 provision would require disclosure or delivery of that source or information solely because of the permitted Game distribution, that requirement is also waived.

This permission also covers the Stakeforge portions of the game-specific tools described in section 2. It does not depend on whether the engine modifications are specific to one Game or could be useful in other games.

The Stakeforge portions remain covered by GPLv3 with these additional permissions. This section does not grant permission to redistribute them as a proprietary standalone engine or development tool. Except as expressly relaxed by this exception, GPLv3 continues to apply.

## 5. Engine derivatives

Distribution of Stakeforge or derivative code as a standalone engine, engine SDK, general-purpose editor, game-making tool, or game-development framework receives none of the Game-specific permissions under sections 3, 4, and 6 of this exception. Such distributions must comply with GPLv3, including its applicable Corresponding Source requirements and required notices.

This applies even if the same modifications were previously used in a Game whose distribution qualified under this exception. Moving, translating, or adapting engine code into different files or components does not avoid these requirements.

Distribution of Stakeforge source code, including modifications, remains subject to GPLv3. Using or modifying an editor privately to make a Game does not by itself require distributing that editor or its source.

## 6. Notices and attribution

For object-code distributions of Game Runtimes and game-specific tools qualifying under sections 2 and 4, providing Stakeforge attribution or credit is entirely optional. You are not required to include or display copies of GPLv3 or this exception, copyright or warranty notices, modification notices or dates, or links to the engine or its license. No separate legal-notices file, credits entry, splash screen, or in-game legal-notices screen is required for the Stakeforge portions.

To that extent, the notice, attribution, modification-marking, and license-copy requirements of GPLv3 sections 4 and 5, including as incorporated by section 6, and the requirement to give notice of these additional permissions under section 7 are waived for those object-code distributions. This waiver does not remove recipients' rights under GPLv3 and this exception, or the warranty disclaimers themselves.

For distributions of Stakeforge source code or of the engines and development tools described in section 5, GPLv3's notice and license-copy requirements continue to apply. As a reasonable attribution requirement under GPLv3 section 7(b), those distributions must also preserve the following notice in an accompanying legal-notices file or an accessible legal-notices screen:

The Game-specific waiver does not apply to distribution of Stakeforge source code, including source distributed alongside a Game. Required third-party notices remain subject to their own terms.

This exception applies only to material whose copyright holders have authorized it. Third-party material remains subject to its applicable licenses.

Recipients may remove the additional permissions as permitted by GPLv3 section 7. Removing those permissions does not remove the attribution requirement for source, engine, and development-tool distributions in section 6, which is a separate term under GPLv3 section 7(b). Copyright holders of modifications may choose whether to grant these additional permissions for their modifications.
